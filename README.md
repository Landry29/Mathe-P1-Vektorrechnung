# 📐 Mathe Praktikum 1 – Vektorrechnung (C++)

Implementierung einer **Vektor-Klasse** in C++ im Rahmen des Moduls *Mathematik 2* an der FH Aachen.

## 📌 Thema

Implementierung mathematischer Vektoroperationen in C++ mit objektorientiertem Design. Die Klasse `CMyVektor` bildet die Grundlage für alle weiteren Mathe-Praktika.

## 🚀 Implementierte Operationen

- Addition und Subtraktion von Vektoren
- Skalarmultiplikation
- Skalarprodukt (Dot Product)
- Betrag / Norm eines Vektors
- Ausgabe von Vektoren

## 🛠️ Technologien & Konzepte

- C++17
- Operator-Überladung (`+`, `-`, `*`, `<<`)
- OOP mit Header/Source Trennung
- Dynamische Speicherverwaltung

## 📁 Projektstruktur

```
Mathe-P1-Vektorrechnung/
├── CMyVektor.h      → Klassen-Definition der Vektor-Klasse
├── CMyVektor.cpp    → Implementierung der Vektoroperationen
└── main.cpp         → Testprogramm mit Beispielberechnungen
```

## ▶️ Kompilieren & Ausführen

```bash
g++ -std=c++17 -o vektor main.cpp CMyVektor.cpp
./vektor
```
